**Chronous – Frontend Watch Website**
**Overview**

Chronous is a responsive watch collection website built using frontend technologies. It focuses on creating a clean user interface, smooth navigation, and an attractive layout for showcasing different types of watches.

**Features**
Responsive design for mobile and desktop
Modern UI with clean layout
Watch collections display section
Interactive buttons and hover effects
Navigation bar and footer
Product showcase with images
**Technologies Used**
HTML5
CSS3
JavaScript
**Project Structure**
index.html – Main webpage
style.css – Styling
script.js – Interactivity
images/ – Assets
**Usage**

Open index.html in any browser to view the website.

**Purpose**

This project is created to practice frontend development and design a real-world product showcase website.
